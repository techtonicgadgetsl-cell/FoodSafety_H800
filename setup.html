⚙️ Set up your area

Each PHI enters their own details once. Nothing needs file editing.

1. PHI & area

2. Firebase (your own project → your own private data)

  1. console.firebase.google.com → create project → Add app (Web) → copy the config.
  2. Build → Authentication → enable E-mail/Password → add staff users.
  3. Build → Firestore Database → create → Rules → paste the rules below.

3. Area boundary (GeoJSON)

Add once – it is kept in this browser and shown on every map.

4. Copy settings to another phone / computer

Export saves PHI details, Firebase config and area boundary in one file. Import it on the other device (or give it to a colleague to start with the same setup).
